# 产品规格

## 产品目标

Real Fund Mobile 是移动端优先的基金持仓 PWA。它不是桌面站的缩小版，而是围绕手机使用习惯重做信息架构，优先支持快速查看持仓、搜索基金、理解市场环境和本地优先的个人数据管理。

## 目标体验

- 主视口按约 `375px` 设计。
- 主导航使用五个移动端标签：持仓、发现、行情、历史、设置。
- 未登录时应用仍应可用。
- 登录用于跨设备同步，不是基础可用性的前置条件。
- PWA 支持包括安装到主屏、离线兜底和 Service Worker 注册。

## 核心路由

- `/portfolio`：持仓总览、持仓表格、收益指标、基金入口。
- `/portfolio/[code]`：基金详情。
- `/portfolio/[code]/manage`：持仓管理。
- `/portfolio/[code]/buy`：买入流程。
- `/portfolio/[code]/sell`：卖出流程。
- `/discover`：基金搜索、预览、添加/追踪流程、最近搜索。
- `/market`：指数、板块、市场快讯、自选指数偏好。
- `/history`：交易历史、筛选、回顾、删除。
- `/settings`：刷新频率、演示数据、备份导入导出、手动云同步、账户状态。
- `/dashboard`：旧驾驶舱页面，代码保留但不在当前主导航中。

## 核心能力

- 通过东方财富公开搜索数据进行基金搜索。
- 通过基金估值数据展示实时估算，必要时使用备选数据源。
- 支持历史官方净值回退。
- 支持持仓和收益计算。
- 支持交易记录管理。
- 支持本地缓存和本地持久化状态。
- 可选接入 Supabase + GitHub 登录进行用户数据同步。
- 支持导入/导出本地状态和应用自有存储快照。

## 持仓展示规则

持仓总览是当前最重要的产品界面。`src/app/portfolio/page.tsx` 和 `buildRows` 是当前核心计算入口。

- 官方链路：`dwjz`、`jzrq`、`zzl`、`officialConfirmedAt`。
- 估值链路：`gsz`、`gztime`、`gszzl`。
- 估值可用性必须走 `isEstimateTimestampUsable`。
- 已确认官方净值应锁定官方展示，避免后续刷新把官方数据回退到旧日期。
- `最新净值`：显示 `dwjz`，日期显示 `jzrq -> MM-DD`。
- `估算净值`：估值可用时显示 `gsz`，否则显示 `-`。
- `昨日涨幅`：显示官方 `zzl`。
- `估值涨幅`：显示 `gszzl`。
- `估算收益`：优先 `(estimateNav - cost) * share`，无估值时回退 `holdingProfit`。
- `持仓金额`：固定官方口径，`share * dwjz`。
- `持有天数`：`holdingDaysInMarket(firstPurchaseDate)`，按北京时间自然日切日。
- `当日收益`：当天官方值可用后使用官方涨幅，否则优先使用估值涨幅。
- `持有收益`：固定官方口径，`(dwjz - cost) * share`。

## 数据与同步行为

- 应用采用 local-first。
- 启动时必须先读取本地 `AppState`、估值序列和关键 UI 偏好。
- 登录后异步比较云端和本地版本，再决定上传、拉取或合并。
- 冲突处理位于应用壳层，必须允许保留本地、保留云端或合并。
- Supabase 同步是可选能力，不应成为正常本地使用的运行时要求。
- 清理流程只能清理应用自有存储命名空间。

## 用户偏好

- 长期 UI 偏好使用 `localStorage`。
- 会话级视图状态使用 `sessionStorage`。
- 需要跨设备同步的偏好通过 `src/lib/user-preferences.ts` 收集，并纳入云同步 payload。
- 当前关键偏好包括持仓列显隐、持仓列顺序、行情页自选指数和手动同步时间戳。

## 已知限制

- 当前未接入交易所法定节假日 API；休市状态主要基于周末和缺失/陈旧数据推断。
- PWA 支持采用基础缓存和离线兜底策略，不是完整离线优先数据架构。
- 第三方基金数据可能延迟、缺失、陈旧或不准确。
